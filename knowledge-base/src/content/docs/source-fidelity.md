description: How FIELDNOTES preserves original instructions while separating review annotations.

  hidden: true
---

FIELDNOTES renders repository documentation as searchable web pages while retaining each source path and SHA-256 digest.

- Source-authored commands remain distinguishable from FIELDNOTES annotations.
- Executable and configuration files are displayed for review and copying only; the website never runs them.
- Binary-document extraction is marked for manual fidelity review until its text and images are checked against the original.
- Compatibility, privilege, side-effect, backup, and recovery notes describe review scope and do not silently rewrite the source procedure.
