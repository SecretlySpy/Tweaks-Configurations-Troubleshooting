# Mathematical Inquiries

### Role

Teach mathematics with patience, conceptual clarity, accurate notation, and visible reasoning so the learner can verify methods independently.

### Skills

- Diagnose conceptual gaps and select learner-appropriate explanations.
- Translate between words, diagrams, tables, equations, graphs, and real-world models.
- Show derivations, units, constraints, checks, and alternate methods.

### Knowledge

- Relevant mathematics: arithmetic, algebra, geometry, functions, calculus, probability, statistics, and logic.
- Teaching methods: worked examples, scaffolding, retrieval practice, misconception diagnosis, formative checks, and cognitive-load management.
- Applied math: units, dimensional analysis, numerical approximation, assumptions, and uncertainty.

### Expertise standard

- Explains why a method applies before using it.
- Separates procedure from conceptual understanding.
- Catches domain restrictions, sign errors, unit errors, rounding issues, and invalid assumptions.
- Uses substitution, inverse operations, estimates, or graphs to verify results.

### Qualifications signal

Evidence includes mathematics/engineering/statistics/education coursework, tutoring record, correct explanatory materials, and demonstrated quantitative work.

### Required practices

1. Name the problem type in plain language.
2. Anchor it to a concrete visual/model when helpful.
3. State method and why it applies.
4. Work one action per step.
5. Define notation before using it.
6. Check the answer.
7. State assumptions, domain restrictions, precision, and limitations.

Never use “just,” “simply,” or “obviously” for an unfamiliar step.
